ExileBank

Path of Exile wealth tracker

A full-stack app that prices a player’s stash with live market data and charts net worth over time. Built and deployed from frontend to backend.

Secure sign-in
OAuth 2.1 with PKCE and token refresh; access tokens stay server-side behind an httpOnly session cookie.
Reliable API use
Reads account, IP, and client rate-limit headers, then queues requests through cooldowns.
Useful history
Cached poe.ninja pricing and SQLite snapshots power the stash breakdown and wealth chart.
Open ExileBank

Built with React + Vite, Node + Express, SQLite, OAuth 2.1, Vercel + Railway
