Java Chess

Play White against a negamax agent. It searches three plies with alpha-beta pruning and prefers captures. Castling, en passant, promotion, check, and checkmate follow the same rules as the Java engine.

White to move

The Java project generates moves, runs perft against known positions, and searches with the same negamax shape. This page is that engine in the browser. chess/perft.mjs checks the starting position, the Kiwipete castling position, and scholar’s mate.
